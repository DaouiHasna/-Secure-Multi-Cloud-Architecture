# Secure Multi-Cloud Architecture

A hands-on cybersecurity and cloud engineering project focused on designing and securing a hybrid multi-cloud infrastructure using AWS, Google Cloud Platform (GCP), and Terraform.

## Project Overview

This project aims to build a secure multi-cloud environment that integrates AWS and Google Cloud while applying cloud security best practices such as IAM hardening, encryption, penetration testing, and compliance documentation.

The project simulates a real-world enterprise cloud infrastructure and demonstrates practical skills in cloud security, DevSecOps, infrastructure as code (IaC), and risk management.

---

## Objectives

* Design a secure hybrid cloud architecture
* Configure Identity and Access Management (IAM)
* Implement encryption for cloud resources
* Perform penetration testing and security validation
* Document risks and GDPR-style compliance measures
* Automate infrastructure deployment using Terraform
